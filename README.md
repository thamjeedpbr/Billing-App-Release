# Billing & Orders — desktop app

The **Windows** and **Mac** apps for Billing & Orders (billing, POS and stock for shops) are published here.
There is no source code in this repository, only the releases and how to install them.

**Download the newest version: [Releases → Latest](../../releases/latest)**
- Windows: `Billing-and-Orders-Setup-<version>.exe`
- Mac: `Billing-and-Orders-<version>-mac-….dmg`

Every version, with what changed, is under [**Releases**](../../releases), tagged `v<version>`.

## Install on Windows

1. Download the setup file (`Billing-and-Orders-Setup-….exe`).
2. Open it. If Windows says *Windows protected your PC*, choose **More info → Run anyway**
   (the app is not code-signed yet).
3. Follow the steps. The app is added to the Start menu and the desktop.

Updates: the Windows app updates itself from this page when a new version is published.
To remove the app: **Settings → Apps → Installed apps → Billing & Orders → Uninstall**.

## Install on Mac

1. Download the `.dmg` file and open it.
2. Drag **Billing & Orders** into **Applications**.
3. The first time only: in Applications, **right-click** the app → **Open** → **Open**
   (macOS asks because the app is not signed by Apple yet).

To update, download the newer `.dmg` and drag the app into Applications again (replace it).
Your data stays on the Mac.

## First start

Choose one:
- **Run the shop on this PC**: the app keeps its own database, so billing works without internet.
  Other PCs, tablets and phones in the shop can open it over the shop's Wi-Fi at the address the app shows.
- **Open the website**: use your online account in the app window (needs internet).

## What the desktop app adds

- Silent receipt (80 mm) and A4 printing to the printers you pick in the **Printers** menu.
- Weighing scale over USB / serial.
- Keeps billing when the internet is down; a daily backup of the shop's data.
